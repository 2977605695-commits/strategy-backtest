## 📐 完整公式

### 一、每日时间线

```
T-1日 15:00 收盘后
  → 采集33只ETF + 10只指数收盘数据
  → 计算所有指标

T日 14:50 尾盘
  → 读昨日信号, 执行买卖
```

### 二、指标计算（全部用T-1日数据）

```
# 均线
MA5  = SMA(close, 5)
MA15 = SMA(close, 15)
MA60 = SMA(close, 60)

# ★ MA三周期投票（消除单一MA8尖峰）
MA7_slope  = LINREG(MA7, 4)  / MA7
MA8_slope  = LINREG(MA8, 4)  / MA8
MA9_slope  = LINREG(MA9, 4)  / MA9
MOMENTUM_ON = (MA7斜率>0 + MA8斜率>0 + MA9斜率>0) >= 2   # 2/3多数

# 趋势信号
TREND_ON = (MA5 > MA15) AND MOMENTUM_ON

# 牛熊判断
HS300_slope = LINREG(HS300的MA60, 20) / MA60
牛市 = HS300_slope >= 0
熊市 = HS300_slope < 0

# 检测池回暖判断
回暖指数 = 10只检测指数中 MA60 20日斜率>0 的个数
```

### 三、买入条件（3道关）

```
条件①: MA5 > MA15                     (中期金叉)
条件②: MOMENTUM_ON                    (MA7/8/9至少2个斜率为正)
条件③: 昨日收盘 > MA60                 (站上年线)

→ 3关全过的标的中, 按 MA5/MA15 比值降序, 买第1名, 满仓
→ 无标的通过则空仓
```

### 四、卖出条件（2个触发器）

```
peak = 持仓期间最高收盘价

触发器A: Trail止损（固定百分比版）
  牛市: 收盘价 ≤ peak × (1 - 3%)
  熊市: 收盘价 ≤ peak × (1 - 6%)

触发器B: 趋势转空
  MA5 < MA15  或  NOT MOMENTUM_ON(MA7/8/9中<2个斜率为正)
  → 任一满足即卖出

谁先触发谁执行。
```

> **注**: 可选叠加ATR自适应Trail（2.0×ATR14，限2%-8%）替代固定3%/6%，
> 经验证可进一步提升夏普至1.24+，但增加复杂度。

### 五、★ 池切换（B版核心改进）

```
当前净值 = 现金 + 持仓市值

ALL → DEF（全池33只 → 防御池9只）
  条件1: 最近5笔交易累计亏损 > 当前净值 × 8%
  条件2: 距上次切换 ≥ 3个交易日（冷却期，防翻烧饼）
  两个条件同时满足 → 切防御池

DEF → ALL（防御池 → 全池）
  条件1: 10只检测指数中 MA60 20日斜率>0 的 ≥ 7个
  条件2: 距上次切换 ≥ 3个交易日（冷却期）
  两个条件同时满足 → 切回全池

防御池(9只):
  黄金×3 (518880/159937/518800)
```

## 🔄 每日操作清单

```
□ 14:50 读信号(昨日数据)

□ Step1: 检查持仓
  ├─ 更新 peak
  ├─ 牛市? 收盘≤peak×0.97 → Trail卖出
  ├─ 熊市? 收盘≤peak×0.94 → Trail卖出
  └─ MA5<MA15 或 投票<2/3 → 趋势转空卖出

□ Step2: 池切换判断（卖出后才判断，且距上次切换≥3天）
  ├─ 在全池? 5笔累计亏>净值8%? → 切防御池
  └─ 在防御池? 7/10指数回暖? → 切回全池

□ Step3: 补仓（空仓时）
  ├─ 从当前池(全池/防御池)筛选
  ├─ 条件: MA5>MA15 + 投票≥2/3 + close>MA60
  ├─ 按 MA5/MA15 比值排序
  └─ 买第1名, 满仓

□ Step4: 记录净值
```
