## 📐 完整公式

### 一、每日时间线

```
T-1日 15:00 收盘后
  → 采集33只ETF + 10只指数的OHLC数据
  → 计算所有指标(MA/ATR/斜率/投票)

T日 14:57 集合竞价下单（实盘建议）
  → 读T-1信号, 执行买卖
  → Step1: 检查持仓(卖不卖?)
  → Step2: 池切换判断
  → Step3: 选股买入(买什么?)
```

### 二、指标计算（全部用T-1日数据）

```python
# 均线（区间均值，消除尖峰）
fast_line = (MA4 + MA5 + MA6) / 3            # 快线=3周期均值
slow_line = (MA14 + MA15 + MA16) / 3         # 慢线=3周期均值

# MA动能投票（消除MA8尖峰）
vote7 = LINREG_SLOPE(MA7, 4) > 0
vote8 = LINREG_SLOPE(MA8, 4) > 0
vote9 = LINREG_SLOPE(MA9, 4) > 0
MOMENTUM_ON = (vote7 + vote8 + vote9) >= 2   # 2/3多数

# 趋势信号
TREND_ON = (fast_line > slow_line) AND MOMENTUM_ON

# 年线过滤（MA95，替代MA60）
ABOVE_TREND = close > MA95

# ATR（自适应Trail）
TR = max(High - Low, |High - 昨Close|, |Low - 昨Close|)
ATR14 = SMA(TR, 14)

# 牛熊判断
HS300_slope = LINREG_SLOPE(HS300的MA60, 20)
牛市 = HS300_slope >= 0
熊市 = HS300_slope < 0

# 检测池回暖
回暖指数 = 10指数中MA60的20日斜率>0的个数
```

### 三、买入条件（3道关）

```
条件①: fast_line > slow_line        (中期金叉)
条件②: MOMENTUM_ON                  (MA7/8/9至少2个斜率为正)
条件③: close > MA95                 (站上近半年线)

→ 3关全过的标的中, 按 fast_line/slow_line 比值降序, 买第1名, 满仓
→ 无标的通过则空仓
```

### 四、卖出条件（2个触发器）

```
peak = 持仓期间最高收盘价

触发器A: ATR自适应Trail（核心改进）
  ATR_trail = 2.5 × ATR14 / peak
  ATR_trail 限制在 [2%, 8%] 之间
  卖出条件: close ≤ peak × (1 - ATR_trail)

  示例:
    低波动(国债, ATR/价≈0.5%): trail=1.25%→限制到2%下限
    中波动(通信, ATR/价≈2%):   trail=5.0%
    高波动(科创, ATR/价≈4%):   trail=10%→限制到8%上限

触发器B: 趋势转空
  fast_line < slow_line 或 NOT MOMENTUM_ON
  → 任一满足即卖出

谁先触发谁执行。
```

### 五、池切换（B版百分比阈值）

```
当前净值 = 现金 + 持仓市值

ALL → DEF（全池33只 → 防御池9只）
  条件1: 最近5笔交易累计亏损 > 当前净值 × 8%
  条件2: 距上次切换 ≥ 3个交易日（冷却期）
  两个条件同时满足 → 切防御池

DEF → ALL
  条件1: 10只检测指数中 MA60 20日斜率>0 的 ≥ 7个
  条件2: 距上次切换 ≥ 3个交易日
  两个条件同时满足 → 切回全池

防御池(9只):
  黄金×3 (518880/159937/518800)
  国债×2 (511010/511260)
  红利×2 (510880/512890)
  上证50 (510050)
  自由现金流 (159301)
```

## ⚠️ 实盘风险提示

### 1. 成交价偏差（最重要）
回测假设收盘价成交，实盘14:50→15:00有10分钟偏差。
- 高波动标的（科创半导体）：偏差约0.5-1%
- **建议**：用14:57集合竞价 + 限价单±0.3%

### 2. 尖峰参数已消除
终极版所有尖峰已通过区间均值/投票机制解决，无已知尖峰参数。

### 3. ATR用当日H/L
14:50时当日H/L不完全确定，但ATR是14日平均，单日偏差影响<2%。

### 4. 历史不代表未来
2025-2026是极端牛市，实盘预期按50-60%折算。

### 5. 实盘监控指标
- 月度信号胜率<40%持续3个月 → 考虑重新优化
- 池切换>10次/年 → 检查百分比阈值
- 单笔亏损>8% → 检查ATR Trail上限
