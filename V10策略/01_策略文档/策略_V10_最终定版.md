## 🧠 MA8 的核心作用（买卖端分离验证）

**MA8 斜率是策略的关键α来源，但它的价值主要在卖出端**：

| 维度 | 33池贡献 | 89池贡献 | 结论 |
|------|:---:|:---:|------|
| MA8 买入端（过滤假金叉）| -0.036 | +0.057 | ○ 轻微/中性 |
| **MA8 卖出端（动能止盈）** | **-0.015** | **+0.188** | **✅ 主要价值** |
| MA8 总贡献（买卖叠加）| +0.105 | +0.326 | ✅ 协同效应 |

**MA8 卖出端的机制**：
- 在价格**还没回撤3%**时（91%的情况），靠动能走弱提前卖出
- 虽然后续54%会继续涨（卖早了），但大幅压缩回撤（无MA8回撤47%→有MA8 35%）
- **本质是"动能止盈器"，不是方向预测器**

## 📐 完整公式

### 数据流（T+1 严格无未来函数）
```
T-1 日收盘 → 计算所有信号(MA/斜率/MA60)
T 日 14:50 → 按昨日信号执行买卖(今日收盘价)
```

### 买入条件（3道关）
```
① MA5 > MA15                    (中期金叉)
② MA8 的 4日斜率 > 0            (短期动能向上)
③ 昨日收盘 > MA60               (站上年线)
→ 通过3关的标的中, 按 MA5/MA15 比值降序, 买第1名, 满仓
```

### 卖出条件（2触发器，谁先到谁触发）
```
触发器A: Trail 止损
  牛市: 收盘价 ≤ peak × (1-3%)
  熊市: 收盘价 ≤ peak × (1-6%)

触发器B: 趋势转空
  MA5 < MA15  或  MA8 斜率 < 0
  (MA8 通常先触发, 占趋势卖出的 90%)
```

### 池切换
```
ALL → DEF (全池33只 → 防御池9只)
  触发: 最近5笔累计亏损 < -100万
DEF → ALL
  触发: 10指数中 MA60 20日斜率>0 的 ≥ 7个
```
