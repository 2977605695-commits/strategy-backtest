## 📌 核心结论

1. **V10真实夏普0.99**（非bug版的1.40），仍是有效的趋势轮动策略
2. **pullback=3%是生死线**，必须精确设置
3. **ETF免印花税**，交易成本极低（0.11%/次）
4. **精选33只标的**贡献约35%的夏普优势（换标的后夏普降至0.56）
5. **熊市MH=7有过拟合嫌疑**（蒙特卡洛10组全票指向0），可考虑删除
6. **6.5年仅2022亏损(-11%)**，其余年度全正
