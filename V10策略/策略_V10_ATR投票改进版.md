## 📐 完整策略流程

### 一、每日执行时间线

```
每个交易日:

T-1日 15:00 收盘后
  → 采集33只ETF + 10只指数的收盘数据
  → 计算所有指标(MA/ATR/斜率)

T日 14:50 尾盘
  → 读取昨日算好的信号, 执行买卖(今日收盘价成交)
  → Step1: 检查持仓(卖不卖?)
  → Step2: 选股买入(买什么?)
```

### 二、信号计算（全部用T-1日数据）

```
MA5  = SMA(close, 5)      # 快线
MA15 = SMA(close, 15)     # 慢线
MA60 = SMA(close, 60)     # 年线

# ★ MA周期投票(改进1): 用3个周期算斜率, 2/3多数同意
MA7_slope  = LINREG(MA7, 4)  / MA7
MA8_slope  = LINREG(MA8, 4)  / MA8
MA9_slope  = LINREG(MA9, 4)  / MA9
MOMENTUM_ON = (MA7斜率>0 的个数 + MA8斜率>0 + MA9斜率>0) >= 2

TREND_ON = (MA5 > MA15) AND MOMENTUM_ON

# ★ ATR(改进2): 真实波动幅度
TR = max(当日最高-最低, |当日最高-昨收|, |当日最低-昨收|)
ATR14 = SMA(TR, 14)

# 牛熊判断
HS300_slope = LINREG(HS300的MA60, 20) / MA60
牛市 = HS300_slope >= 0
熊市 = HS300_slope < 0
```

### 三、买入条件（3道关，全部满足才买）

```
条件①: MA5 > MA15              (中期金叉)
条件②: MOMENTUM_ON             (MA7/8/9至少2个斜率为正)
条件③: 昨日收盘 > MA60          (站上年线)

→ 3关全过的标的, 按 MA5/MA15 比值降序, 买第1名, 满仓
→ 若空仓且无标的通过 → 继续空仓
```

### 四、卖出条件（3个触发器，谁先到谁触发）

```
峰值 peak = 持仓期间最高收盘价

触发器A: ★ ATR自适应Trail (核心改进)
  Trail线 = peak × (1 - ATR_trail)
  ATR_trail = 2.0 × ATR14 / peak   (波动大→止损宽, 波动小→止损紧)
  ATR_trail 限制在 2% ~ 8% 之间     (防止极端值)
  卖出条件: 收盘价 ≤ peak × (1 - ATR_trail)

触发器B: 趋势转空
  MA5 < MA15  或  MOMENTUM_OFF(MA7/8/9中<2个斜率为正)
  → 任一满足即趋势转空, 卖出

触发器C: 池切换强制平仓(见第六节)
```

### 五、ATR Trail 工作示例

```
场景1: 通信ETF(低波动, ATR/价格≈1.5%)
  ATR_trail = 2.0 × 1.5% = 3.0%  → 紧止损, 快锁利

场景2: 科创半导体(高波动, ATR/价格≈4%)
  ATR_trail = 2.0 × 4% = 8.0%    → 宽止损, 抗震荡洗出

场景3: 国债ETF(极低波动, ATR/价格≈0.5%)
  ATR_trail = 2.0 × 0.5% = 1.0%  → 限制到下限2%

场景4: 2022熊市(波动飙升, ATR/价格≈6%)
  ATR_trail = 2.0 × 6% = 12% → 限制到上限8% → 比固定6%更宽, 避免假止损
```

### 六、自适应池切换

```
ALL → DEF (全池33只 → 防御池9只)
  触发: 最近5笔累计盈亏 < -100万(初始资金10%)
  动作: 下次选股只从9只防御ETF中选

DEF → ALL
  触发: 10指数中 MA60 20日斜率>0 的 ≥ 7个
  动作: 恢复33只全池

防御池(9只): 黄金×3 + 国债×2 + 红利×2 + 上证50 + 自由现金流
```

### 七、每日操作清单

```
□ 14:50 检查当前持仓
  ├─ 更新 peak
  ├─ 算 ATR_trail = 2.0 × ATR14 / peak (限制2%-8%)
  ├─ 若 收盘 ≤ peak×(1-ATR_trail) → ATR Trail卖出
  └─ 若 MA5<MA15 或 投票<2/3 → 趋势转空卖出

□ 检查池切换
  ├─ 5笔累计亏损<-100万? → 切防御池
  └─ 7/10指数回暖? → 切回全池

□ 若空仓, 选股买入
  ├─ 筛选: MA5>MA15 + 投票≥2/3 + close>MA60
  ├─ 排序: MA5/MA15 比值降序
  └─ 买入第1名, 满仓

□ 记录当日净值
```

## 🔬 改进原理

### 改进1: ATR自适应Trail 为什么有效

**问题**: 固定3% Trail 对所有标的"一刀切"
- 通信ETF(日均波动1.5%): 3%止损=2天波动, 太容易被洗
- 科创半导体(日均波动4%): 3%止损=0.75天波动, 几乎每天都会触发

**解决**: ATR让止损随波动率自适应
- 低波动标的 → ATR小 → 止损紧 → 快锁利
- 高波动标的 → ATR大 → 止损宽 → 抗洗出
- 熊市波动飙升 → ATR自动放大 → 避免密集假止损

**效果**: 2022年从-22%到0%(波动飙升时止损自动放宽)

### 改进2: MA周期投票 为什么有效

**问题**: 单一MA8周期=8是极端尖峰(±1格夏普暴跌0.3)

**解决**: MA7+MA8+MA9 三周期投票, 2/3多数同意
- 平滑掉单一周期的噪音
- 不再依赖某个"神奇数字"
- 邻域稳定性大幅提升

**效果**: 消除尖峰, 信号更稳健

## ⚠️ 风险提示

1. **ATR上限8%** — 个别高波动标的(科创半导体)止损可能偏宽, 实盘需观察
2. **2023年回退** — ATR版本在2023少赚19%(纳指那波止损偏宽), 这是用波动适配换稳健的代价
3. **89池有2/10组失败** — ATR对某些标的组合偏宽, 整体8/10胜出但非100%
4. **改进版偏右偏分布** — 大部分时候改善, 少数情况变差, 实盘需持续监控
