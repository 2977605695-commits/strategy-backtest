## 二、策略1：纯双动量选股（Pure Dual Momentum）

### 2.1 核心理念

截面动量（买强者）+ 绝对动量过滤（避开下跌趋势）。三时间窗口加权，长周期占主导。

### 2.2 信号公式

```
三个窗口动量（学术标准：长周期跳过最近1个月避免短期反转）：
  M_short = close / close[21d]  - 1         （1个月全段）
  M_mid   = close / close[63d]  - 1         （1季度全段）
  M_long  = close[21d] / close[126d] - 1    （t-21到t-126，跳最近1月）

综合得分：
  Score = Z(M_short)×0.2 + Z(M_mid)×0.3 + Z(M_long)×0.5

绝对动量过滤器：
  M_long > 0    （扣除最近1个月后，过去半年仍涨 = 趋势有效）
```

### 2.3 操作规则

| 参数 | 值 |
|------|-----|
| 调仓频率 | 每月第一个交易日 |
| 持仓数 | 5只（得分最高） |
| 权重 | 等权各20% |
| 过滤 | M_long ≤ 0 跳过 |
| 不足5只 | 剩余现金 |
| 止损 | 单只 -15% 硬止损 |
| 卖出 | 月频调仓时不在新Top5则卖 |

### 2.4 回测参数

| 参数 | 值 |
|------|-----|
| 回测区间 | 2021-01 → 2026-07（需至少126d预热） |
| 初始资金 | 1,000,000 |
| T+1 | 是（买入日次日方可卖出） |
| 滑点 | 0.3% |
| 佣金 | 0.025% |
| 印花税 | 0.05%（仅卖出） |
| 现金收益 | 年化 2.5% |

## 三、策略2：风险调整趋势强度（Risk-Adjusted Trend）

### 3.1 核心理念

不用涨跌幅，用MA交叉结构判断趋势质量。波动率惩罚确保偏好"稳步涨"而非"暴涨暴跌"。与策略1形成天然互补。

### 3.2 信号公式

```
三层MA趋势确认（每满足1条 +1分，总分 0~3）：
  T1 = MA5  > MA20    （短线趋势）
  T2 = MA10 > MA50    （中线趋势）
  T3 = MA20 > MA100   （长线趋势）

原始得分 = (T1+T2+T3) / std(close, 20d) × close

截面标准化：
  Score = Z(原始得分)
```

### 3.3 操作规则

| 参数 | 值 |
|------|-----|
| 调仓频率 | 每周一检查 |
| 持仓数 | 5只 |
| 权重 | 波动率倒数加权：w_i = (1/σ_i) / Σ(1/σ_j) |
| 最低门槛 | 趋势强度 ≥ 2（至少2条MA满足） |
| 不足5只 | 剩余现金 |
| 卖出 | 趋势强度跌破 1 → 立即卖出 |
| 硬止损 | 单只 -10% |

### 3.4 波动率倒数加权

```
σ_i = std(close_i, 20d) / close_i    （20日波动率）

仓位_i = (1/σ_i) / Σ(1/σ_j)

→ 低波动股票多配（涨得稳），高波动股票少配（涨得猛但可能闪崩）
```

### 3.5 回测参数

| 参数 | 值 |
|------|-----|
| 回测区间 | 2021-01 → 2026-07（需100d MA预热） |
| 初始资金 | 1,000,000 |
| T+1/滑点/佣金/印花税 | 同策略1 |
| 现金收益 | 年化 2.5% |

## 五、三条策略预期特征对比

| 维度 | 策略1·双动量 | 策略2·趋势强度 | 策略3·基本面抄底 |
|------|:---:|:---:|:---:|
| 收益来源 | 截面动量溢价 | 低波动+趋势 | 均值回归+基本面 |
| 买入时机 | 已经涨了（追涨） | MA结构多头（顺势） | 跌多了（抄底） |
| 调仓频率 | 月频 | 周频 | 事件触发 |
| 预期夏普 | 0.8-1.2 | 1.0-1.5 | 1.5-2.1 |
| 预期回撤 | 20-30% | 10-18% | 17-19% |
| 牛市中表现 | 强（追涨追到） | 中（稳步跟上） | 弱（牛不回踩） |
| 熊市中表现 | 中（绝对动量减仓） | 强（波动率降仓） | 强（抄底反弹） |
| 震荡市中表现 | 弱（反复止损） | 中（MA反复交叉） | 强（反复抄底） |
| 与策略3相关性 | 预计低/负相关 | 预计低正相关 | — |

## 六、相关性预期 & 组合逻辑

策略1（追涨）和策略3（抄底）理论上负相关——策略3在策略1止损后入场，策略1在策略3止盈后接力。策略2（趋势质量）居中，与两者低正相关。

如果实测相关性 < 0.3，三策略等资金组合后的夏普可望达到 **2.0-2.5**。
