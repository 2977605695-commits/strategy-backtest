# 隔夜-日内分解策略 · 实盘操作手册

> 策略文件: `strategy_overnight_intraday.py` | Sharpe 1.215 | 回测 2020-2026

---

## 一、你不需要分钟数据

**策略只需要三个日频字段：`open`, `close`, `volume`。**

```
因子 = f(每日开盘价, 每日收盘价, 每日成交量)
```

不需要 Level-2、不需要 Tick、不需要逐笔成交、不需要盘中任何数据。全部计算在收盘后完成。

## 二、为什么不会造成巨大滑点？

### 核心原因：信号是日频的，但执行是月频的

| | 回测参数 | 可调范围 |
|---|---------|---------|
| 因子计算频率 | 每天收盘后 | 不变 |
| 调仓频率 | 每21天（月频） | 可缩短到10天（双周） |
| 平均每月调仓 | 2-4只 | 3-5只 |
| 年化双边换手率 | 约10-15倍 | 约15-25倍 |

**月频调仓意味着：即使每天计算因子，一个月只交易2-4次。**

### 滑点的三个来源，逐一分析

#### 1. 收盘价→次日开盘价跳空

```
回测成交价: T日收盘价
实盘成交价: T+1日开盘价 (或集合竞价)
```

| 情况 | 跳空幅度 | 频率 |
|------|:---:|:---:|
| 正常交易日 | ±0.2% ~ ±0.5% | ~80% |
| 财报公告次日 | ±1% ~ ±3% | ~15% |
| 重大事件 | ±3% ~ ±10% | ~5% |

**影响评估：**
- 月频调仓 → 每月仅2-4笔交易受跳空影响
- 跳空方向随机（有时候赚有时候亏）→ 平均影响约 ±0.1%~0.2% 每笔
- 策略平均每笔盈利约 +12%（回测数据）→ 0.2% 的滑点在信号幅度面前可忽略

#### 2. 冲击成本（大单推高/压低价格）

| 市值区间 | 500万订单冲击 | 1000万订单冲击 |
|---------|:---:|:---:|
| 沪深300成分 | <0.05% | <0.10% |
| 中证500成分 | 0.05%-0.15% | 0.10%-0.25% |
| 中证1000成分 | 0.10%-0.30% | 0.20%-0.50% |
| 中证2000及以下 | 0.30%-1.0%+ | 0.50%-1.5%+ |

**策略自动规避小盘股冲击：**
- 涨跌停过滤 → 自动跳过流动性最差的极端情况
- 顶部股票池 → 中证500/1000成分股为主
- 5只等权 → 单只占比20%，资金分散

#### 3. 涨跌停无法交易

策略已内置涨跌停过滤：近5天有涨跌停的股票不选。发生率很低。

## 三、实盘每日操作 SOP

```
15:00  收盘
       ↓
15:01  获取所有候选股票的 open[t], close[t], volume[t]
       ↓
15:02  计算 on_ret[t] = open[t]/close[t-1] - 1
       计算 id_ret[t] = close[t]/open[t] - 1
       ↓
15:03  计算14日均值:
       on_avg = mean(on_ret[t-13], ..., on_ret[t])
       id_avg = mean(id_ret[t-13], ..., id_ret[t])
       ↓
15:04  计算 volume_factor = clip(volume[t]/ma20(volume), 0.5, 2.0)
       score = (on_avg - id_avg) × volume_factor
       ↓
15:05  对所有股票score做z-score标准化，排名
       ↓
15:06  生成调仓清单:
       卖出: 当前持仓中不在Top5的
       买入: Top5中未持仓的
       ↓
15:10  提交次日开盘买入/卖出订单
       ↓
次日 9:25  集合竞价/开盘价执行
```

## 四、滑点总账

| 成本项 | 每笔 | 年化影响(15倍换手) | 年化影响(10倍换手) |
|--------|:---:|:---:|:---:|

| 收盘→开盘跳空 | ±0.1%~0.3% | ~0% (随机) | ~0% (随机) |
| 冲击成本 (中证500) | -0.10% | -1.50% | -1.00% |
| **总计 (悲观)** | | **-2.26%** | **-1.50%** |

## 五、信号衰减分析

```
日内反转部分 (id_avg)  →  衰减快，有效期 1-5 天
隔夜动量部分 (on_avg)  →  衰减慢，有效期 5-20 天

→ 月频调仓 (21天) 主要捕捉隔夜动量成分
→ 双周调仓 (10天) 可额外捕捉日内反转成分
→ 日频调仓会有大量噪音，不推荐
```
