## 完整策略逻辑 (逐行注解)

```python
# ============================================================
# 🔧 可调参数区
# ============================================================
LOOKBACK = 14          ← [可调] 隔夜/日内收益的均线周期 (天)
                           越长越平滑 → 信号噪音小但滞后
                           越短越灵敏 → 交易多但噪音大
                           回测最佳: 14天 (5~21均可用)

TRAIL = 0.10           ← [可调] 移动止损线 (%)
                           从买入后最高点回落10%就卖
                           回测最佳: 10% (5%~25%均可用)

REBAL_DAYS = 21        ← [可调] 再平衡周期 (天)
                           每21天重新排名，换掉掉出前5的
                           回测最佳: 21天 (5/10/21均可用)

VOL_FILTER = True      ← [可调] 是否启用成交量增强
                           成交量/20日均量 → 截断在[0.5, 2.0]
                           回测最佳: True

MAX_POS = 5            ← [可调] 持仓数量
                           5只等权 (各20%)
                           回测最佳: 5只 (2~8均可用)

INIT_CAP = 10_000_000  ← 初始资金
SLIP = 0.003           ← 滑点 (双边千三)
COMM = 0.00025         ← 佣金 (万2.5)
STAMP = 0.0005         ← 印花税 (万5, 仅卖出)
RF = 0.025             ← 无风险利率 2.5%

# ============================================================
# 数据: 每个股票每天只需要3个字段
# ============================================================
# open[t]    ← 当日开盘价
# close[t]   ← 当日收盘价
# volume[t]  ← 当日成交量

# ============================================================
# 步骤1: 分解每日收益为两段
# ============================================================
def decompose(bars):
    """
    bars[i] = {open, close, volume}
    """
    on_ret = []   # 隔夜收益: 前收 → 当日开盘
    id_ret = []   # 日内收益: 当日开盘 → 当日收盘

    for i in range(1, len(bars)):
        # 隔夜: 从昨天收盘到今天开盘
        on = bars[i].open / bars[i-1].close - 1

        # 日内: 从今天开盘到今天收盘
        id = bars[i].close / bars[i].open - 1

        on_ret.append(on)
        id_ret.append(id)
```

## 📊 因子计算

```
每一天, 对每只股票:

步骤1: 过去14天隔夜收益均值
  on_avg = mean( on_ret[t-13], on_ret[t-12], ..., on_ret[t] )
  解读: 最近两周, 机构隔夜配置方向

步骤2: 过去14天日内收益均值
  id_avg = mean( id_ret[t-13], id_ret[t-12], ..., id_ret[t] )
  解读: 最近两周, 散户盘中博弈方向

步骤3: 原始得分
  raw_score = on_avg - id_avg
  解读: 隔夜动量延续 + 日内超卖反转

步骤4: 成交量增强
  vol_ratio = clip(volume[t] / MA20(volume), 0.5, 2.0)
  score = raw_score × vol_ratio
  解读: 放量信号更可靠, 缩量信号打折

步骤5: 截面z-score标准化
  把所有股票的score做(z - μ)/σ → 排名
  选Top 5买入, 等权各20%
```
